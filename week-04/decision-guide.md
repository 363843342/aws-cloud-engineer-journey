
| AWS Service | Use This When... |
| :--- | :--- |
| **S3** | Use this when you need scalable, durable object storage for unstructured data (like images, logs, or backups) accessible over HTTP/S. |
| **EBS** | Use this when you need low-latency block storage attached to a single EC2 instance, such as for a root OS drive or application volume. |
| **EFS** | Use this when you need a fully managed, scalable NFS file system that can be shared concurrently across multiple Linux EC2 instances. |
| **RDS** | Use this when you need a managed relational database for structured data with support for SQL queries, complex joins, and ACID compliance. |
| **DynamoDB** | Use this when you need a fully managed NoSQL key-value/document database designed for single-digit millisecond latency at any scale. |
